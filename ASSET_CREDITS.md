# Visual assets

- `assets/montreal-autumn.png`: original AI-generated pixel-art illustration created for this portfolio with OpenAI image generation. Directed around Montréal landmarks, autumn foliage, a raised Mount Royal, UdeM, triplexes, the Olympic Stadium, downtown and the Old Port. It is a stylized illustration, not an exact geographic map.
- Pepper: original local CSS pixel sprite.
- Ferry: original inline SVG pixel sprite, animated in a clipped river lane.
- `assets/favicon.svg`: existing project icon.

The user's supplied city illustration was a visual reference. Its artwork was not copied or redistributed. No third-party asset pack is included.

The original résumé PDFs remain in the repository for preservation, but the interface does not link to them. Contact details shown by the portfolio are limited to the approved email address.
